# Currículum web de Rodrigo Merino

Sitio estático, adaptable a móviles y preparado para publicarse con GitHub Pages.

## Personalización

El contenido se encuentra en `index.html` y el diseño en `styles.css`. Antes de publicar,
reemplaza los textos de ejemplo, el correo y el enlace de LinkedIn con los datos reales.

## Vista local

Abre `index.html` directamente en un navegador o ejecuta un servidor estático en esta carpeta.
